УРОК 1. ПРАКТИКА GIT

Цель: пройти базовый цикл Git самостоятельно и понять состояние файлов
на каждом шаге.

1. До начала работы создай ветку:
   git switch -c lesson/01-basics

2. Инициализируй Go-модуль в корне репозитория:
   go mod init github.com/Amaym0n/go-start

3. После каждого существенного изменения выполняй:
   git status
   git diff

4. Перед коммитом выполни проверки из PDF урока.

5. Добавь изменения в индекс и проверь, что именно попадет в коммит:
   git add .
   git diff --staged

6. Создай коммит:
   git commit -m "Complete lesson 1 Go basics"

7. Посмотри историю:
   git log --oneline --decorate -5

8. Отправь ветку на GitHub:
   git push -u origin lesson/01-basics

9. Пришли наставнику вывод команды:
   git rev-parse --short HEAD

Вопросы, на которые нужно ответить своими словами:

1. Чем рабочая директория отличается от staging area (индекса)?
2. Что делает git add и почему эта команда не создает коммит?
3. Зачем перед коммитом смотреть git diff --staged?
4. Что означает параметр -u при первом git push новой ветки?
